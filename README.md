# Woolsey Fitness

## The premier, official app for the Woolsey Fitness brand, based out of Livermore, California!

Woolsey Fitness brings the studio experience directly to members’ fingertips. Designed to complement the Woolsey Fitness studio, the app provides a centralized place for members to explore classes, manage their fitness experience, and access guided workout programs.

Our goal is to make fitness more accessible, organized, and engaging while bringing the Woolsey Fitness brand into a seamless digital experience.

## About the App

The Woolsey Fitness mobile app is being developed as the official digital companion to the Woolsey Fitness studio.

The application is designed around three core experiences:

* Studio Experience: Explore class offerings, view schedules, and manage class bookings.
* Self-Guided Training: Access structured workout programs designed by Woolsey Fitness trainers.
* Member Experience: Manage a personal profile and access member-focused features.

## Features

### Home

* Personalized member greeting.
* Profile photo and account access.
* Membership credit overview.
* Upcoming class information.
* Featured studio content and links to social platforms.

### Class Schedule

* Browse available studio classes.
* View class dates, times, and instructors.
* Book and manage classes.

### Workout Programs

* Explore programs from Woolsey Fitness and Move with Justine.
* Follow structured workouts organized by stations and exercises.
* Track completed workout rounds.
* Support for progressive training programs.

### Member Profile

* Personalized member profile.
* Profile photo selection and management.
* Centralized member information.

### Technology Stack

The application is built using:

* React Native – Cross-platform mobile application framework.
* Expo – Development and application tooling.
* TypeScript – Strongly typed application development.
* Expo Router – File-based navigation.
* AsyncStorage – Local persistence for selected member preferences and profile data.

### Planned Integrations

The long-term goal is to connect the application to the studio’s existing systems and provide a fully integrated member experience.

* Mindbody API: Membership information, class schedules, reservations, and booking management.
* Backend Services: Secure authentication, member profiles, workout data, and application data persistence.
* Trainer Administration: Tools for authorized Woolsey Fitness staff to create, manage, and publish workout programs.

### Development

This project is actively being developed. Features and integrations are being implemented incrementally, with an emphasis on maintainability, usability, and a consistent Woolsey Fitness brand experience.
